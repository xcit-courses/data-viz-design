# Data Visualization and Design Exercises

This folder contains interactive R exercises for the Data Visualization and Design course.

## Using Exercises with Binder

You can complete these exercises without installing R locally by using Binder:

1. Click the Binder badge in the main README
2. Wait for the environment to load (first time may take a few minutes)
3. RStudio will open in your browser with all exercises ready to use
4. Navigate to the `exercises/` folder
5. Open any `.R` or `.Rmd` file to start working

## Exercise Structure

Exercises are organized by chapter:

- `chapter1/` - Introduction exercises
- `chapter2/` - Grammar of graphics exercises
- `chapter3/` - Distribution visualization exercises
- `chapter4/` - Relationship visualization exercises
- `chapter5/` - Customization exercises
- `chapter6/` - Interactive visualization exercises
- `chapter7/` - Advanced topics exercises

## Working Locally

If you prefer to work on your own computer:

1. Clone this repository
2. Install R and RStudio
3. Install required packages: `source("install.R")`
4. Open the exercises in RStudio

## Tips

- Save your work frequently
- Try modifying the examples to explore different options
- Refer to the course slides and resources for help
